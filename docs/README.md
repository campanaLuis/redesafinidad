# Documentación técnica — Red Afinidad (app Lovable)

Esta carpeta documenta **diseño visual**, **arquitectura de datos**, **funcionamiento** y la **“fórmula” de experiencia** (rapidez percibida, responsividad) para poder **replicar el mismo enfoque** en otro proyecto.

| Documento | Contenido |
|-----------|-----------|
| [01-diseno-sistema-visual.md](./01-diseno-sistema-visual.md) | Tokens CSS, Tailwind, shadcn/ui, layout móvil, componentes propios |
| [02-arquitectura-datos-y-backend.md](./02-arquitectura-datos-y-backend.md) | Rutas, Supabase, Edge Function, BD externa, flujo de datos |
| [03-rendimiento-y-formula-ux.md](./03-rendimiento-y-formula-ux.md) | Por qué se siente rápida la app, límites con BD grande, checklist para el nuevo proyecto |

**Stack resumido del repositorio:** Vite 5, React 18, TypeScript, Tailwind CSS 3, shadcn/ui (Radix), TanStack React Query, Supabase JS, React Router 6.
